# 图表阅读指南

## 先分清图在回答什么

训练曲线表示学习过程，固定任务图表示命令能力，故障曲线表示特定注入下的首回合响应，MSE曲线表示学生对teacher动作的离线拟合。它们不能直接合成同一个总分，也不能把回合数合并成独立训练重复。

## 英文坐标和单位

| 英文 | 中文读法 | 怎么看 |
|---|---|---|
| iteration | 原日志迭代编号 | 2026在恢复边界重复标签，不能只按最大编号算实际rollout |
| rollout | 一批PPO采样及更新 | 原训练每批4096×24条转移；不等于一个完整回合 |
| elapsed time | 各运行日志的经过秒数 | 恢复段时钟单独记录，不与迭代轴混淆 |
| mean reward | 训练平均回报 | 受课程、奖励权重和命令分布影响，不是安全分数 |
| mean_reward_per_step | 每环境步的平均奖励 | T训练记录定义，不能直接与原4000轮mean_reward数值比较 |
| Episode_Reward | 训练奖励分项 | 按代码权重缩放，没有跨分项统一物理尺度 |
| Episode_Termination | 训练日志终止聚合 | 不可直接乘100解释为固定评估跌倒率 |
| survival / success_rate | 规定观察时长存活比例 | 本项目success旧字段实际为存活，不是任务完成率 |
| not yet terminated | 尚未发生终止的比例 | 从首回合终止时间重算，20秒超时不是死亡 |
| mean seconds / duration | 首回合有效寿命秒 | 早终止越多通常越低；要与速度误差同时看 |
| vx error | 前向速度绝对误差 m/s | 通常越低越好，但早停可能截短统计 |
| XY velocity error | 平面速度向量误差 m/s | 不等同单独vx误差 |
| yaw error | 竖直轴旋转速度误差 rad/s | Turning还要看平移漂移，不能只看yaw |
| action delta L2 | 相邻网络动作的L2变化 | 不等于真实电机力矩或损伤 |
| max tilt | 最大倾角 度 | 注意pre-step记录可能漏终止物理帧 |
| MSE | 学生与teacher动作的平方误差 | 离线低误差不保证闭环能走 |
| pp | 百分点 | 90%到80%为-10个百分点，不是-10%相对变化 |
| count | 归一化历史样本计数 | 来源账本；900的virtual mass不是实际收集量 |
| w | 人工矩合并的新部分有效权重 | 不是新增PPO训练步数 |
| p | 新部分内的污染比例 | p=0为同w clean，对照不等于原模型 |
| F / U | 统计冻结 / 沿历史追加 | F仍训练网络权重，不是整个模型冻结 |
| T0 / TC / TI | clean / 共同旋转 / 相反旋转 | 仅T真实PPO干预合同 |

## 误差条不是同一种东西

Wilson区间描述固定模型在给定回合分布中的存活比例；回合bootstrap有它自身重采样单位；三个评估seed的极值竖线只是范围，不是95%训练总体置信区间。11个三seed均下降的剂量格不是11个统计显著发现，共享clean与嵌套样本使网格相关。

## 读图顺序

先确认模型来源和协议，再看分母及评估seed，随后对照存活、寿命、跟踪误差，最后阅读反证和限制。不同故障的同alpha不代表等输入范数；冻结步数与额外延迟也不代表硬件总时延。类别点不连线，有限端点连线不补测量，未测不填0。
